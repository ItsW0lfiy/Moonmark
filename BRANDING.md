# Moonmark branding

Moonmark's source code is licensed under GPL-3.0-only. That license permits copying, modification, and redistribution under its terms; this branding policy does not limit those software freedoms.

The Moonmark name, logo, wordmark, and official release presentation identify the upstream Moonmark project. Modified or independently distributed builds should use names and presentation that do not imply they are official Moonmark releases, endorsed by Moonmark, or published by ItsW0lfiy.

Accurate factual references to Moonmark, attribution, compatibility statements, and descriptions of a fork's origin remain welcome. This policy is intentionally separate from the software license.
