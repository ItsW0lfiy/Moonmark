# Next steps

Moonmark's active implementation milestone is `0.1.0-dev.7`: First Windows Release & Shell Integration. Shell arguments, version metadata, portable release staging, and checksums can proceed now. The setup executable, Open With registration, and physical install/upgrade/uninstall matrix remain gated on explicit selection of the installer engine; the current recommendation is recorded in [docs/INSTALLER_EVALUATION.md](docs/INSTALLER_EVALUATION.md).

After dev.7 is locally complete and explicitly authorized for publication, `0.1.0-dev.8` remains the updater milestone. Do not begin update checks or background update behavior during dev.7.

See [ROADMAP.md](ROADMAP.md) for the development-channel, updater, WinGet, Linux, Android, editor, settings, and packaging direction.
